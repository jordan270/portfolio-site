# Garv Kapoor Portfolio

A Vite and TypeScript portfolio with a WebGL particle hero, project slides, and contact links.

## Run locally

```powershell
npm install
```

```powershell
npm run dev
```

```powershell
npm run build
```

```powershell
npm run preview
```

## Assets

Public images, icons, and fonts live in `public/`; particle shape samplers and the rendering engine live in `src/engine/`. The `private/` directory is local-only and must never be committed.

**Live site:** https://portfolio-site-one-zeta-85.vercel.app/
